## Running an Exercise

You need a C++ compiler, such as GCC or Clang.

Each exercise is intended to be compiled and run separately. For example, from the repository's main folder:

```bash
g++ -std=c++17 Loops/while.cpp -o exercise
./exercise
```

Replace `Loops/while.cpp` with the path to the exercise you want to run. On Windows, compile with `-o exercise.exe` and run `.\exercise.exe` in PowerShell.
